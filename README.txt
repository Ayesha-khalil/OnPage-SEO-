SAFFRON & SMOKE — RESTAURANT WEBSITE

HOW TO RUN IN VISUAL STUDIO CODE
1. Download and extract this ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted saffron-smoke-restaurant folder.
4. Open index.html.
5. Right-click the file and choose "Open with Live Server" (install the Live Server extension if needed).
   You can also double-click index.html to open it in your browser.

FILES
- index.html: website content and sections
- style.css: colours, layout, responsive design and animations/transitions
- script.js: mobile navigation and demo reservation form

IMPORTANT
- This is a front-end demo. The reservation form displays a confirmation message but does not send a real booking.
- Food photography and Google Fonts require an internet connection.
- Replace the sample restaurant name, prices, phone number, address and email with your own details.
